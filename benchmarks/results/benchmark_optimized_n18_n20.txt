自己回避経路 探索最適化結果（n=18,19,20）
===============================================

作成物
------
ソース: moto_probe_optimized.cpp
ビルド: build_probe_optimized_cpp.bat
実行物: moto_probe_optimized.exe

既存の moto_probe_exact.cpp は変更していない。
比較元は benchmark_n18_n20.txt の384ビット正確演算結果。
各 n の制限時間は60秒。

最適化内容
----------
1. rank表の分割位置
   Motzkin語長が奇数のとき、開始高さ別に複製される第2表を短くした。

2. rank第2表の32ビット化
   最終チャンクでは終端高さを後続処理で使わないため、順位差分だけを保持した。
   rank表の概算サイズは次のように減少する。
   n=18: 約82 MiB  -> 約19 MiB
   n=19: 約96 MiB  -> 約52 MiB
   n=20: 約360 MiB -> 約80 MiB

3. ページローカル16ビット添字
   64K rankページ内の状態番号を32ビット大域添字から16ビット局所添字へ変更した。
   ページ本体は約320 KiBから約194 KiBとなり、約39%縮小した。

4. 256状態単位の再利用チャンクプール
   巨大な active_keys / active_values vector を廃止した。
   再確保時の巨大コピー、余剰capacity、ページごとの値配列確保を避け、
   状態をrankページ単位で連続走査することで局所性も改善した。

5. 多倍長値の不要コピー削減
   addの384ビット値引数を値渡しからconst参照へ変更した。

正確性確認
----------
n=0～16について既存384ビット版と比較し、以下がすべて一致した。
  ・paths
  ・peak states
  ・transitions

完走比較:
  n=15 既存13.329秒 -> 最適化版12.866秒
  n=16 既存48.112秒 -> 最適化版41.100秒

--------

注意
----
n=20のメモリ効率は改善したが、完走時の最大状態数は今回の60秒計測範囲外である。
64 GB環境でのn=20完走を保証するものではない。さらに必要なら、rank分割・外部保存・
複数パス方式を次段階として組み合わせる必要がある。
